まずはお金の減算関数から。

お金はMain領域に最初から入っているのでポインタコードを作るのは簡単だった。

でもこれじゃ面白くないので解析。

- 0x003DECB0 は、桃鉄２（mt2w）の クランプ付き所持金 setter 関数 Main+0x003DEC20〜0x003DED00 の中の書き込み命令。
- 所持金フィールド = [obj+0x88]（64bit signed）。0x3DECB0: str x8, [x19, #0x88] がその代入命令。
- 代入前に [-99,999,999, +999,999,999] にクランプ（上限 0x3B9AC9FF、下限 0xFA0A1F01、ともに10進検証済み）。
- 上限到達で [obj+0x180] bit4 が立つ。プラス→マイナス転落時のみ借金イベント分岐。
- 呼び出し元 26箇所の中核 setter。

``` armasm
0x00DE26C0: ldr  x16, [x0, #0x88]    ; x16 = 旧所持金
0x00DE26C4: cmp  x1, x16
0x00DE26C8: csel x1, x1, x16, gt     ; 新 ≤ 旧 なら x1=旧（減らさない）／新 > 旧 なら増加はそのまま通す
0x00DE26CC: stp  x29, x30, [sp, #-0x20]!   ; 退避した元命令
0x00DE26D0: b    #0x3DEC24           ; フック直後へ復帰
```

これでお金が減らなくなる。全プレイヤー共通なのでキー判定と組み合わせて使えば自分だけ減らない、って事が可能。
