## ミートカーソル

```
[共通_ミートカーソルストライクゾーンオートエイム制限解除]
04000000 02C73D0C D503201F
04000000 02C73D2C D503201F
04000000 02C73D4C D503201F
04000000 02C73D6C D503201F
```

最初に作ったプログラム系コード、オートエイムのヒントがあったので簡単だった。

```asm
; オートエイム関数 FUN_2c736b4（0x2C736B4〜0x2C73EEC）
; ミートカーソル座標を計算→ボールへ吸着→最後にストライクゾーンへクランプして書き戻す

; ★★ ストライクゾーン・クランプ（4つ）★★
02C73CFC: blr x8          ; 境界値ゲッター呼び出し → s0 = 境界
02C73D00: ldr s1, [sp,#0x10] ; s1 = 現在のカーソルX
02C73D04: fcmp s1, s0
02C73D08: b.pl 02C73D10   ; 範囲内ならスキップ
02C73D0C: str s0, [sp,#0x10] ; ★ 境界値でカーソルを上書き = 制限本体 → NOP
```

`D503201F` = NOP（ARM64の「何もしない」命令）。4つのクランプ命令を NOP で潰すと、計算後のカーソルがゾーン外に出られるようになる。

## オリジナル変化球

```
[オリジナル変化球 制限解除]
04000000 027BA18C 713FFC9F
04000000 027BAEC0 713FFC1F
```

合計ポイントの上限チェック（cmp w20, #0x65 ≒ 101）を cmp w20, #0xfff（4095）に書き換えることで、クランプ処理に到達しなくさせる。

```asm
; パッチ前 → パッチ後
027BA18C: cmp w20, #0x65  →  cmp w20, #0xfff  ; 0x7101969F → 0x713FFC9F
027BAEC0: cmp w0,  #0x65  →  cmp w0,  #0xfff  ; 0x7101941F → 0x713FFC1F
```

`cmp wN, #imm` は実体が `SUBS wzr, wN, #imm12` で、12ビットの即値がそのまま命令語に埋まっている。`0x065 → 0xFFF` に変えるだけで、条件分岐には一切触らず「比較する数字だけ」を大きくしている。

```
[オリジナル変化球 フィールド最大値解除]
04000000 027B2464 D503201F
04000000 027B2654 D503201F
```

各球種の変化量制限を撤廃。メモリを超えるとエラーになる点に注意。

## 変化球

```
[共通 変化球変化量2倍]
04000000 02C768C8 52A85E08

[共通 変化球変化量3倍]
04000000 02C768C8 52A86688

[共通 変化球変化量4倍]
04000000 02C768C8 52A86E08

[共通 変化球変化量5倍]
04000000 02C768C8 52A872C8
```

```asm
; Main+0x02C767C4 ＝ 投球されたボールの毎フレーム更新
; 変化量振幅 → 1フレあたりの「破壊速度」へ変換（リリース時1回だけ）

02C768C8: mov w8, #0x42700000 ; ★ = 60.0 ← 120/240/300 に書き換えるレバー
02C768D0: fmov s4, w8          ; s4 = 60.0（パッチ後 120/240/300）
02C768E4: fmul s2, s2, s4      ; 縦振幅 × 60 ← ここで倍化
02C768E8: fmul s3, s3, s4      ; 横振幅 × 60 ← ここで倍化
```

s4（=60.0）が横・縦の振幅両方に掛かるので、`02C768C8` を一箇所いじるだけで両方向の曲がりが増える。

表示されているカーソル以上に曲がっても打てるということはオートエイム関数同様に投球時の着弾箇所を計算して確率で打っていると断定。

```asm
0114A7B0: cmp  w24, #9        ; w24 <= 9 なら天才肌
0114A7B4: b.hi 0x114a7d4      ; w24 > 9 → 通常抽選へ ← ここをNOPで常に天才肌

; 排出率の検証
01149988: msub w21, w9, w10(#1000), w8  ; w21 = w0 % 1000（母数1000）
0114998C: cmp  w21, #9                   ; 天才肌 ⟺ w21 ≤ 9（0〜9の10通り）
; → 10 / 1000 = 正確に1.00%
```

攻略サイトの天才肌の排出率1%が正しいのか検証してみた。正確に1.00%だった。
